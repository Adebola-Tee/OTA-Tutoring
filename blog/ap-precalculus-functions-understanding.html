AP Precalculus functions

How to Make AP Precalculus Functions Easier to Understand

By Taiwo Oloyede6 October 20264 min read

A function question can look like four different topics. There is an equation on one page, a table on another, a graph on the next and a description of a changing quantity. Students may learn each procedure separately without recognising the relationship they share.

AP Precalculus becomes clearer when those views are connected. The aim is to understand what inputs are allowed, how outputs change and which features survive when the representation changes.

Begin with inputs and outputs

For f(x) = x squared, input 3 gives output 9. Asking for f(3) means evaluating the function at that input. Asking where f(x) = 9 means finding inputs that give the stated output.

Over the real numbers, those inputs are 3 and minus 3. That difference matters: evaluation at one input and solving for an output are not interchangeable tasks. A learner who treats every function question as substitution will miss the second demand.

Draw the graph and identify both points at height 9. The picture should explain the algebraic result, rather than serve as an unrelated drawing exercise.

Read a rational function carefully

Consider f(x) = (x squared minus 1) divided by (x minus 1). Factoring the numerator allows the expression to simplify to x + 1, provided x is not 1.

The original denominator is zero at x = 1, so that input remains excluded. The graph follows the line y = x + 1 with a hole at the point (1, 2). Simplification does not restore the missing input.

Ask the student to produce three pieces of evidence: the original denominator, the simplified expression with its restriction and the corresponding graph feature. When those agree, the rule about exclusions has a reason.

Use tables to notice relationships

Choose a few permitted inputs and compare the outputs. What happens when the input rises by one? Does the output change by a constant amount or by a constant factor? Those patterns can help distinguish linear and exponential behaviour.

Be careful about conclusions from a short table. Several points can fit more than one model. A proposed relationship should also match the context and its assumptions, rather than being declared correct because a graphing tool produced a neat curve.

This is part of the translation between representations described in the official AP Precalculus course. The table, formula and graph should help answer the same mathematical question.

Give transformations a meaning

Before memorising a transformation rule, try a familiar function. If g(x) = f(x) + 2, each output is two greater at the same input. The graph moves upward by two units.

For a change inside the input, such as f(x minus 2), ask which new input produces the old output. Working through a point can explain the horizontal shift and prevent relying on a half remembered slogan about moving left or right.

Practise moving in both directions

Include a question where the input is meaningful only over a limited range, such as time since an event began. A mathematical formula may accept negative values, while the stated model may not. The student should distinguish the algebraic domain from the domain appropriate to the situation.

After drawing a graph from a formula, describe a graph feature and ask for an algebraic explanation. After evaluating a table, ask what a value means in a context. The learner should be able to travel back as well as forward.

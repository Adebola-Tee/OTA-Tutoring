GCSE Computer Science Tutoring

How to find a GCSE Computer Science tutor for programming

By Taiwo Oloyede3 October 20264 min read

“My child can copy Python code, but cannot write a program from a question.” That is a useful thing to tell a prospective GCSE Computer Science tutor. It describes the point where a lesson must do more than demonstrate a finished answer on a screen.

Start by checking the student's exam board, specification and language used at school. Do not assume every GCSE course assesses programming in the same way. For example, AQA's Computer Science specification sets out programming and algorithm work, while its subject content explains the languages and skills relevant to that specification. A tutor should match the learner's actual course and exam year.

Ask to see the learner explain code

One short exercise reveals much more than a list of languages on a tutor's profile. Give the student a small loop that adds numbers until a condition is met. Ask them to predict the output, trace two passes by hand and explain when the loop stops.

If they can follow the code but cannot design their own loop, the gap is in translating a problem into steps. If they cannot predict what a variable holds after one pass, start with tracing. These require different first lessons.

For example, imagine a program that adds the prices of three items. A learner may write `total = price` inside the loop and accidentally reset the total each time. Instead of immediately replacing that line with the correct one, ask them to trace the value after item one, item two and item three. The bug becomes something they can see and explain.

Ask how the tutor handles a wrong answer

Good programming lessons make room for mistakes. Ask whether the tutor will help the student read an error message, test a small case and change one thing at a time. If the tutor takes control of the keyboard and produces working code, the learner can leave with a polished program and the same underlying confusion.

The student should sometimes write pseudocode or a plain English plan before touching the editor. Other times they should inspect existing code and explain why it fails. AQA's algorithm guidance includes representing algorithms through pseudocode, program code and flowcharts, but the school's specification should guide the exact practice.

Try an independent follow up: change the problem from three items to an unknown number of items. Can the learner adapt the plan without being told where every line goes? That shows whether they understood the loop or remembered one answer.

Match tutoring to the assessment and the child

Ask the teacher or child which tasks are currently hardest: writing code, tracing code, logic, data representation or explaining an algorithm in an exam answer. A programmer can be excellent at building apps and still need to understand how to teach a particular GCSE question.

Our broader guide to GCSE programming and algorithms tutoring covers the subject as a whole. For a child struggling specifically to begin a programming task, one marked school question and one short program are better starting materials than a long catalogue of topics.

Agree a measurable first goal. It might be tracing a loop accurately, spotting where a variable changes or writing and testing a short solution from a plan. Ask the tutor how they will check the skill a week later without giving the same example again.

If that sounds like the support your child needs, bring the specification, recent feedback and a program they found difficult to our free parent consultation. We can discuss an appropriate first lesson and whether online programming support fits their course.

# Chat and WhatsApp widgets

The website now loads:

- Tawk.to live chat
- A WhatsApp enquiry button linked to `+234 807 967 5840`

Both widgets appear on every current website page. The blog generator has also
been updated, so articles created later with `BUILD_BLOG.bat` will include them
automatically.

## Receiving Tawk.to messages

Sign in to the Tawk.to dashboard or mobile app to receive and answer live-chat
messages. Configure email notifications inside Tawk.to so offline messages and
missed chats reach your email.

## Changing the WhatsApp number or greeting

Open `contact-widgets.js`.

- Change `whatsappNumber` to another number using digits only and including the
  country code.
- Change `message` to edit the greeting placed in WhatsApp.
